## 3. 高权重论文详细拆解

### P03. IGF2BP3 通过 USP10 调节 p53 稳定性

基本信息：Zhao W、Lu D 等，Oncotarget，2017，DOI 10.18632/oncotarget.21280。Dan Lu 为共同第一作者，参与构思、假设界定、实验、分析和初稿写作，归因 W3。

起始 observation 是 IGF2BP3 在肺癌中高表达且与较差结局相关，但表达关联不能说明驱动作用，也不能解释其 RNA 结合以外的功能。scientific question 是 IGF2BP3 是否通过蛋白稳态而非转录调节 p53。中心假设为 IGF2BP3 与 USP10 结合，削弱 USP10 对 p53 的稳定作用，促进肿瘤生长与转移。

主要模型包括患者组织、公开数据库、p53 阳性与缺失细胞、IGF2BP3 高低不同的细胞、裸鼠皮下成瘤和尾静脉转移。顺序是人类相关性，细胞双向扰动，体内表型，互作质谱，内源与外源互作，p53 mRNA、半衰期和泛素化，再比较 p53 背景。

Loss of function 是两个 IGF2BP3 shRNA，gain of function 是稳定表达和多个独立克隆。没有标准野生型回补，p53 阳性与缺失背景只能提供部分依赖性。正交证据包括公开数据、qPCR、IHC、增殖、迁移、转移、质谱、共沉淀、半衰期和泛素化。p53 mRNA 不变排除主要转录解释，内源互作降低纯过表达伪影。

最决定性的证据是双向扰动产生相反功能表型，IGF2BP3 与 USP10 互作并改变 p53 半衰期和泛素化，以及 p53 背景差异。可删的是重复数据库、重复增殖读出和过细结构域图。删除双向扰动或蛋白稳态证据会明显削弱主结论。机制停在 IGF2BP3、USP10 与 p53 稳定性，没有证明 IGF2BP3 如何改变 USP10 催化。新增类型是 RNA 结合蛋白的非经典蛋白调控关系。

### P08. PTENα 限制 CTL 诱导的肿瘤铁死亡

基本信息：Sun Y、Lu D 等，Nature Communications，2021，DOI 10.1038/s41467-021-25417-6。Dan Lu 为共同第一、共同通讯，参与主要实验、分析、监督和写作，归因 W4。

起点是不同 PTEN 失活突变具有不同免疫特征和结局。问题是终止突变背景中的 PTENα 是否让肿瘤靶细胞抵抗 CTL 杀伤。假设链为 PTENα 去磷酸化 eIF2α，限制应激颗粒，维持 GPX4 等过氧化物酶翻译，降低脂质氧化和铁死亡，减少 DAMP 并促进免疫抵抗。

模型跨越人群突变数据、Pten 缺失 B16 与 PTENα 重构、CT26、肿瘤疫苗、裸鼠过继 T 细胞、免疫完整小鼠、慢性 LCMV、Ptenα 缺失鼠和互换骨髓嵌合。实验先定位临床悖论和残余蛋白，再区分基础生长与免疫选择，随后完成细胞死亡分类、宿主来源定位、翻译和下游上位性。

Loss of function 包括 Ptenα 缺失和 Gpx4 敲低。Gain of function 是 Pten 缺失背景中的 PTENα 及变体重构。Rescue 包括 Fer1、DFO、α 生育酚和纳米维生素 E，Gpx4 敲低又消除 PTENα 的保护。遗传、药理和骨髓嵌合证据相互补充。基础增殖、T 细胞输入、胞外分泌形式和其他死亡方式均被定向排除。

最决定性的证据是 PTENα 只在免疫压力下带来生长优势，骨髓嵌合把作用定位到非造血靶细胞，以及铁死亡干预和 Gpx4 上位性把分子机制连到体内肿瘤结局。可删的是部分 TIL 亚群、重复氧化指标和未进入主链的蛋白组候选。机制停在翻译调控和铁死亡抵抗，不追全部应激颗粒成分。新增类型同时包括 isoform 功能、靶细胞免疫抵抗概念和跨层机制。

### P09. OTUD1 稳定 IREB2 并增强抗肿瘤免疫

基本信息：Song J 等，EMBO Reports，2021，DOI 10.15252/embr.202051162。Dan Lu 为共同通讯和共同构思者，主要实验由其他作者完成，归因 W3。

起点是结直肠癌中 IREB2 蛋白下降而 mRNA 未同步下降，且泛素化增加。问题是哪种去泛素化酶维持 IREB2，以及肿瘤铁代谢如何连接 CD8 T 细胞免疫。假设为 OTUD1 去除 IREB2 泛素链，维持 TFRC 和铁摄取，使肿瘤细胞更易发生免疫原性铁死亡并激活 T 细胞。

模型包括患者组织、OTUD1 与 Ireb2 缺失细胞、野生型与 C320S OTUD1、CT26 和 LLC、免疫完整与 NOD-SCID 宿主、Otud1 缺失鼠、铁饮食、AOM/DSS 和肿瘤疫苗。互作质谱后进入直接去泛素化、半衰期、底物依赖、铁摄取、免疫宿主比较和疾病模型。

核心 loss of function 为 OTUD1 和 Ireb2 缺失，gain of function 为野生型 OTUD1，C320S 是酶活阴性对照。Ireb2 缺失消除下游效应，纳米维生素 E 逆转体内抑瘤。免疫缺陷宿主中抑瘤消失，排除单纯基础生长效应。Fer1 与其他死亡抑制剂的差异支持铁死亡。

决定性证据是野生型与 C320S 的差别、Ireb2 上位性、免疫完整与缺陷宿主差别，以及抗氧化逆转。宽泛贫血表型、重复 DAMP 和第二细胞系部分结果可以精简。机制停在 OTUD1、IREB2、TFRC、铁死亡、DAMP 和 CD8 反应，没有定位单一 DAMP 受体。新增类型是去泛素化、铁代谢和免疫原性死亡的跨细胞连接。

### P10. NEURL3 对 IRF7 K375 进行 K63 泛素化

基本信息：Qi F 等，FASEB Journal，2022，DOI 10.1096/fj.202200316R。Dan Lu 为末位唯一通讯，与 Fang Qi 共同构思和设计，参与写作，归因 W4。

起点是病毒感染条件下 IRF7 互作质谱发现 NEURL3。问题是 NEURL3 是否选择性调控 IRF7，使用何种链型和位点，又如何影响抗病毒转录。假设为感染后 NFκB 诱导 NEURL3，NEURL3 对 IRF7 K375 进行 K63 泛素化，使 HDAC1 解离并提高启动子 H3K27ac 和 ISG 转录。

模型包括多种细胞、VSV 和 SeV、Neurl3 缺失小鼠，以及 NEURL3 RING 删除、C217Y、IRF7 K375R、14KR 和 13KR 加 K375 等构建体。顺序从互作筛选进入特异性、感染动力学、酶活、链型、位点、染色质机制和敲除鼠感染结局。

Loss of function 包括 Neurl3 缺失、酶活失活和 K375R。Gain of function 是野生型 NEURL3。位点级 add back 是在几乎无赖氨酸背景单独恢复 K375。正交证据包括质谱、内外源共沉淀、链型、位点、报告、病毒滴度、ChIP 和动物生存。IRF 家族比较、链型比较、酶活突变、核定位和 IRF7 乙酰化阴性结果分别处理特异性解释。

决定性证据是酶活缺陷同时消除泛素化和功能，K375 丢失与单点恢复，以及 Neurl3 缺失鼠内源泛素化、ISG、病毒负荷和死亡同向改变。部分结构域、基础表达和上游启动子细节可删。机制停在 NEURL3、IRF7 K375、HDAC1 与 H3K27ac。新增类型是位点特异 PTM 与抗病毒染色质激活的连接。

### P12. 突变 RIGI 通过 circRIGI 增强炎症

基本信息：Song J 等，Nature Communications，2022，DOI 10.1038/s41467-022-34885-3。Dan Lu 为末位共同通讯和共同构思者，归因 W4，但研究由多位共同监督作者完成。

起点是 DDX58 移码变体按常理应造成 RIGI 功能丢失，对应模型却出现更高 IFN 和炎症。问题是突变前体 RNA 是否获得新的环状 RNA 信号功能。假设为移码突变改变 RNA 结构和 DHX9 结合，增加 circRIGI，后者作为支架促进 DDX3X、MAVS、TRAF5、TBK1 和 IRF3 信号。

模型包括患者胚系变异、CRISPR Rigifs/fs 小鼠、MEF、iBMDM、AOM/DSS、单独 AOM、单独 DSS、LPS、VSV、骨髓嵌合、人 CRC 和 UC 组织。实验从人群变异进入模型忠实性，再拆分致癌与炎症，定位细胞来源，确认环状 RNA 身份，做选择性连接位点敲低与过表达，定位下游复合体，最后用 ATRA 逆转。

Loss of function 包括 circRIGI 连接位点 shRNA 及 DDX3X、MAVS、IRF3 等下游敲低。Gain of function 是 circRIGI 表达。ATRA 体内逆转但缺少 circRIGI 再回补，因此药物特异性有限。RNase R、反向 PCR、连接位点测序、Northern 和 FISH 正交确认环状 RNA。单独 AOM 与 DSS、骨髓嵌合、外源 IFN 旁路和环状与线性转录本区分处理主要替代解释。

决定性证据是致癌与炎症拆分及非造血来源定位，circRIGI 的选择性 loss 和 gain 配对，以及 DDX3X、MAVS、IRF3 依赖和体内逆转。宽泛患者亚组、部分 LPS 或病毒扩展和互作组非核心候选可删。机制停在突变前体 RNA、DHX9、circRIGI 和 DDX3X 信号复合体。新增类型是突变到异常剪接再到 RNA 支架信号的机制。

### P13. VHL、BICD2、STAT1 与结晶性肾损伤

基本信息：Hao W 等，Cell Death and Disease，2023，DOI 10.1038/s41419-023-06185-1。Dan Lu 为共同通讯，与 Wenyan Hao 共同构思设计并参与写作，归因 W4。

起点是草酸钙刺激后肾小管 VHL 上调。问题是该变化为保护性反馈还是损伤驱动，作用是否依赖经典 HIF。假设为 VHL 促进 BICD2 K48 泛素化和降解，限制 BICD2 介导的 STAT1 核转位，维持 system xc 并降低铁死亡。

模型包括结晶性肾损伤小鼠、Vhl 杂合突变鼠、HK-2、VHL 缺失 786-O、COM 和多类死亡刺激。顺序是体内表型，HIF 排除，TurboID 和质谱提名 BICD2，互作与泛素化，BICD2 双向扰动，死亡类型，STAT1 定位和 system xc，另扩展 vemurafenib 支线。

Loss of function 包括 Vhl 突变、BICD2、HIF1A 和 HIF2A shRNA。Gain of function 包括 VHL、BICD2、STAT1 和位点构建体。BICD2 敲低消除 VHL 保护，Fer1 与 DFO 消除 BICD2 相关死亡差异。缺少 Vhl 小鼠中的下游遗传救援。HIF 敲低与多类死亡抑制剂针对最强替代解释。

决定性证据是相同结晶负荷下 Vhl 突变加重损伤，BICD2 依赖与 K48 泛素化，以及 BICD2 双向扰动和铁死亡抑制。宽免疫面板、重复活力读出和药物毒性支线可删。机制停在肾上皮 VHL、BICD2、STAT1、system xc 和铁死亡。新增类型是疾病保护通路，并附带药物毒性解释。

### P14. RPA1 缺失导致 T 细胞坏死性凋亡和炎症

基本信息：Song J 等，Advanced Science，2023，DOI 10.1002/advs.202206344。Dan Lu 为末位共同通讯，承担共同构思、设计、监督、经费和写作，归因 W4。

起点是 RPA1 在增殖性 T 细胞激活中升高，而多类自身炎症患者 T 细胞中下降。问题是复制压力管理如何维持外周 T 细胞，以及 T 细胞减少为何反而加重炎症。假设为 RPA1 缺失造成 DNA 损伤和胞质 DNA，激活 ZBP1、RIPK3、MLKL 坏死性凋亡和 DAMP，继发髓系反应。

## 7. 归因与方法边界摘要

最可靠的方法画像来自 W4 原创机制论文的重复结构，而不是题目词频或期刊层级。W3 论文主要用于检查规则是否跨疾病和跨平台重现。W2 和 W1 论文用于补充或发现边界，例如纯相关研究应停止在关联层，共同通讯但职责未细分的论文不能进入核心归因，综述和评论不能贡献原创实验频次，合作平台技术不能自动归因给 Dan Lu。

完整证据矩阵显示，并不存在每篇论文都使用同一套技术的固定流程。稳定之处是先定位问题和细胞层级，再用能够改变所支持主张或补齐证据维度的少数实验修补最薄弱连接；模型、技术和 rescue 形式随主张改变。
