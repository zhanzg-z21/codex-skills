# 中文长篇小说创作系统

## 设计哲学

本skill不是"AI替你写小说"，而是"AI作为你的资深编辑搭档，帮你把脑子里的故事变成文字"。
核心理念：**深度定制 > 批量生产，迭代打磨 > 一次成型**。

---

## 创作流程总览

整个创作分为三个阶段，用户可以从任意阶段开始：

```
阶段一：世界构建（首次创作必须）
  → 采访式深度对话 → 世界观圣经 + 人物档案 + 悬念追踪表

阶段二：逐章创作（核心循环）
  → 加载上下文 → 写本章 → 质量自查 → 更新进度追踪器 → 循环

阶段三：润色与反AI（可选，推荐）
  → 逐章精修 → Anti-AI检查 → 定稿
```

---

## 阶段一：世界构建

当用户第一次说"我想写一部小说"时，不要急着写正文。先做深度采访。

### 1.1 深度采访（非选择题模式）

与用户进行对话式采访，逐步挖掘故事内核。采访分为五轮，每轮聚焦一个维度。
不要一次性抛出所有问题，逐轮推进，每轮根据上一轮回答调整方向。

**第一轮：灵感种子**
- 你脑子里已经有什么画面或场景了吗？哪怕只是一个模糊的感觉也行。
- 有没有哪部作品（小说/动漫/电影/游戏）的某个设定让你特别兴奋？
- 你想写给谁看？自己爽？给朋友看？上平台连载？

**第二轮：世界观内核**
- 这个故事发生在什么样的世界？和现实有什么不同？
- 这个世界有什么独特的"规则"是其他故事里没有的？
- 这个规则会如何影响普通人的日常生活？

**第三轮：角色与关系**
- 主角是什么样的人？不是"性格标签"，而是：他/她平时怎么说话？遇到危险第一反应是什么？最怕失去什么？
- 谁是主角最重要的人？这段关系的"压力点"在哪里？
- 有没有一个让你自己都觉得"这个角色好可怕/好可惜/好复杂"的对手？

**第四轮：情节骨架**
- 故事的起点是什么？（主角的日常被什么打破了）
- 中间最大的转折是什么？（读者会"卧槽"的那个瞬间）
- 结局你心里有方向吗？（开放式？反转？牺牲？治愈？）

**第五轮：风格与调性**
- 你希望读者看完是什么感觉？（烧脑？心碎？热血？细思极恐？）
- 节奏偏好：快节奏网文爽感，还是慢热文学质感？
- 叙事视角：第一人称（代入感）还是第三人称（信息操控）？

### 1.2 生成创作文件包

采访完成后，生成以下文件（全部为Markdown格式）：

**文件1：世界观圣经（world-bible.md）**
参考 `references/world-bible-template.md` 生成。包含：
- 公理层（世界观的根规则，1-3条，所有设定从此推导）
- 时代与地点
- 势力/阵营设定
- 核心角色卡（每人一张，含性格、说话方式、核心恐惧、叙事功能）
- 角色关系网
- 情节节点（已确定的关键转折）
- 悬念追踪表（已挖的坑，计划填坑位置，状态）
- 主旨提炼
- 写作备忘

**文件2：进度追踪器（progress-tracker.md）**
参考 `references/progress-tracker-template.md` 生成。包含：
- 已完成章节摘要表
- 当前活跃线索表（线索、开启于、紧迫度、状态）
- 时间线（故事内日期 → 事件 → 章节）
- 下一次写作备忘

**文件3：写作系统提示词（writing-prompt.md）**
参考 `references/writing-prompt-template.md` 生成。包含：
- 作者人设（风格定位）
- 叙事规则（视角、篇幅、节奏、对话风格）
- 写作禁区（具体的禁止项，不是笼统的"写得好"）
- 一致性规则（确保前后不矛盾的具体约束）
- 章节写作指令模板
- 质量自查清单

这三个文件构成了这部小说的"操作系统"，后续每次创作都要加载。

## 阶段二：逐章创作

### 2.1 上下文加载

每次写新章节前，确认以下文件已在上下文中：
1. 世界观圣经
2. 进度追踪器
3. 写作系统提示词
4. 上一章全文（至少最后一章，建议最近两章）

如果用户只说"写下一章"但没有提供这些文件，主动提醒：
"我需要你的世界观圣经和进度追踪器才能保持连贯性。能把这些文件发给我吗？"

### 2.2 章节创作流程

**Step 1：确认本章方向**
与用户确认：
- 本章核心事件（必须有）
- 出场角色
- 需要埋的新伏笔（如果有）
- 需要推进/回收的旧伏笔（查进度追踪器）
- 章末钩子方向
- 特殊要求

**Step 2：写正文**
遵守写作系统提示词中的所有规则。特别注意：
- 开头不要重复上一章结尾的信息，直接往前推
- 每章至少一个"爆点"（发现/冲突/反转/情感高潮）
- 章末必须有钩子
- 字数控制在3000-5000字

**Step 3：质量自查**
写完后，对照 `references/quality-checklist.md` 逐项检查。
将检查结果简要告知用户，标出需要注意的点。

**Step 4：更新进度追踪器**
自动更新以下内容：
- 本章摘要（字数、时间线、出场角色、核心事件、伏笔、钩子）
- 活跃线索表（新增/推进/关闭）
- 时间线
- 下一章写作备忘

### 2.3 创作节奏参考

| 章节位置 | 节奏 | 重点 |
|---------|------|------|
| 第1-3章 | 稳 | 建世界观、立人物、第一个大悬念 |
| 第4-8章 | 加速 | 展开第二条线、引入对手、信任裂痕 |
| 第9-12章 | 密集 | 中期反转、信念动摇、情感炸弹 |
| 第13-16章 | 再加速 | 多线收束、真相逼近 |
| 第17-20章 | 高潮+收束 | 终极选择、伏笔回收、情感落点 |

## 阶段三：润色与反AI

### 3.1 Anti-AI写作检查

每章定稿前，检查以下AI写作痕迹并修正：

**高频词禁用表（出现即改）：**
- 动词：delve into, shed light on, orchestrate, elucidate, underscore, navigate
- 形容词：robust, pivotal, multifaceted, intricate, nuanced, comprehensive
- 名词短语：able landscape, able paradigm, growing body of evidence
- 句式：It is worth noting that..., plays a crucial role in..., remains unclear

**中文AI腔禁用表：**
- "值得注意的是"、"不禁让人想到"、"这无疑是"
- "仿佛在诉说着"、"似乎在暗示着"、"不由得感叹"
- 过度使用"然而"、"与此同时"、"不言而喻"
- 每段都以四字成语结尾
- 排比句超过三组

**结构性AI痕迹：**
- 每个场景转换都用分隔符（应该自然过渡）
- 每章都以天气/时间描写开头
- 对话后必跟心理描写（应该留白）
- 所有角色说话风格趋同（应该有个性区分度）
- 情绪描写过度直白（"他感到恐惧" → 用身体反应代替）

### 3.2 润色原则

参考 `references/polish-guide.md` 进行润色。核心原则：
- **展示而非讲述**：用动作和细节代替抽象描述
- **留白大于填满**：不是每个情绪都要写出来
- **具体大于笼统**：不说"她很漂亮"，说"她扎着一个低马尾，碎发贴在鬓角"
- **节奏感**：短句制造紧张，长句制造松弛，交替使用

---

## 用户已有作品时的处理

如果用户已经有世界观、大纲、或已写章节：
1. 先通读所有已有素材
2. 理解并尊重已有设定，不擅自修改
3. 基于已有素材生成/补全创作文件包
4. 从用户当前进度继续
