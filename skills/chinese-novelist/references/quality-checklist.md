# 质量检查清单

> 每章写完后逐项检查。分为"必须通过"和"建议优化"两档。

---

## 必须通过（不过不交稿）

### 一致性
- [ ] 角色名字、身份、年龄与世界观圣经一致
- [ ] 本章事件不与已写章节矛盾
- [ ] 故事内时间线前后连贯（检查进度追踪器）
- [ ] 世界观硬规则没有被违反
- [ ] 上一章的章末钩子在本章有回应（不一定解答，但不能无视）

### 结构
- [ ] 本章有至少一个"爆点"
- [ ] 章末有悬念钩子
- [ ] 字数在目标范围内（±500字容差）

### 叙事视角
- [ ] 没有泄露视角角色不可能知道的信息
- [ ] 其他角色的内心想法只通过言行暗示，没有直接写出

---

## 建议优化

### 节奏
- [ ] 没有连续超过5段纯叙述（应穿插对话或动作）
- [ ] 没有超过3行的心理描写块
- [ ] 没有超过3行的环境描写块（除非环境即情节）
- [ ] 场景转换自然，不依赖分隔符硬切

### 对话
- [ ] 每个角色说话有辨识度（遮住名字能猜出谁说的）
- [ ] 没有"为了解释设定而说的台词"
- [ ] 对话中有潜台词（角色嘴上说的和心里想的不完全一致）

### 感官细节
- [ ] 本章至少有2个具体的感官细节（味道、触感、声音等）
- [ ] 情绪通过身体反应表达，而非直接陈述
- [ ] 有至少1个"只有这个角色才会注意到的细节"

### Anti-AI
- [ ] 没有使用禁用词表中的词汇
- [ ] 没有AI腔结构（排比超三组、段末四字成语、过度使用转折词）
- [ ] 开头不是天气/时间描写（除非与情节直接相关）
- [ ] 不同角色的语言风格有明显区别

---

## 检查流程

1. 写完初稿后，先通读一遍，标记"感觉不对"的地方
2. 对照"必须通过"清单逐项检查
3. 对照"建议优化"清单查漏补缺
4. 针对标记的问题逐一修正
5. 更新进度追踪器
