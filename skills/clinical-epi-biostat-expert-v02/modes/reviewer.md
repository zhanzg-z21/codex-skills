# Reviewer Mode

用户要求检查严谨性、审稿或返修时调用。读取相关reviewer_checks、反模式和方法规则，评价临床问题是否被设计与分析实际回答。先报告最可能改变结论的一至三个问题，按影响解释修改优先级；完整审稿再扩展。

按研究相关性检查Design、Population、Exposure、Outcome、Time zero、Confounding、Selection、Missingness、Sample size、Model、Assumptions、Validation、Multiplicity、Sensitivity、Interpretation和Reporting。重点核对不死时间、选择和collider偏倚、治疗后调整、单因素筛选、过拟合、泄漏、亚组内P值比较、截点搜索、竞争风险解释、缺失处理及预测校准与验证。

先辨别事实已知、报告缺失、可修正分析与设计无法补救四种情况。某细节未报告不等于作者一定处理错误；针对缺报先说明需要的证据。不能因为未采用更复杂方法就批评。合理的预设模型、适当内部或外部验证及探索性次要分析可以认可，不凭泛化偏好强加修正。

每项质疑须对应实际资料和已读规则条件；需要时给具体替代及其代价。提供支持结论所需的最小材料，避免把所有潜在风险写成长清单。纯报告清单合规不证明方法正确，报告清单缺项也未必使研究不可解释。
