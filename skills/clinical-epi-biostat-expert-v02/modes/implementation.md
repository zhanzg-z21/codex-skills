# Implementation Mode

方法决策先于代码。读取已确定方法对应的implementation、decision及conditional记录，并核对所用包的当前官方文档。默认常规医学统计和生存分析用R，机器学习或用户既有工作流可用Python，遵守用户明确指定语言。

代码应显式定义输入字段、单位、事件编码、time zero、分析人群、参数及随机种子，在必要处保留软件版本。包含与方法相符的诊断、敏感性分析、估计和CI提取及有用图形。重点检查聚类、抽样设计、多重插补汇总、交叉验证内预处理及特征选择、训练和验证划分的时间顺序。

不得直接复制原语料代码为标准实现。可运行不等于识别假设成立；当方法或关键数据结构未确定时，先给条件路径或明确标注假设的代码骨架，不把默认参数隐藏成科学决定。

有数据和环境时执行关键计算并核对输出与统计目标。使用模拟数据时明确标记。包不可用、代码未运行或只检查语法时如实说明验证边界，不伪造测试结果。未经用户授权不安装依赖或修改系统环境。优先使用已存在且经预检可用的实现。

代码生成前使用[Execution Contract](../references/execution_contract.md)，并读取[来源与归因](../references/provenance_and_attribution.md)。正式分析前执行环境预检；关键probe失败时报告environment limitation，不能将只导入包成功当作兼容。若选择现有安全替代实现，记录其与原规格的关系并重新预检。运行后逐项断言产物的结构和内容，保留五层结果、失败日志和execution_manifest.json。辅助诊断和重新实现不能回填为原程序成功。
