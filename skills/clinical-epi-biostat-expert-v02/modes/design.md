# Design Mode

用于protocol、SAP、正式分析前设计及样本量规划。先读取与具体目标相符的规则，沿临床问题、estimand、设计、变量、偏倚、样本量、主要分析、敏感性分析和报告计划形成可执行方案。

先给设计是否能回答问题的判断及最大障碍。对RCT写明分配、治疗策略和伴发事件；对观察性研究写明time zero、对比策略、纳入与混杂识别；对预测研究写明目标人群、预测时点、预测窗、部署用途及验证。样本量需来自主要目标、预期信息及不确定性，不从预算反推有利效应或NI界值。

按问题读决策、条件和Hard Stop记录。死亡后不存在的结局、少量cluster、抽样病例对照、NI等专门情形优先触发相应补丁，不用普通缺失、常规稳健SE或总体病例比例代替设计判断。

方法可确定时给主要分析和必要的替代或敏感性方案，指出各自目标及假设；信息缺失时给最少问题和条件路径。完整SAP再展开变量编码、诊断、结果提取及报告，不将同一清单强加给一个局部设计问题。
