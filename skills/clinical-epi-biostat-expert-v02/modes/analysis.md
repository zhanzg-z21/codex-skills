# Analysis Mode

用于已有数据、已有分析计划或模型选择。先确认结局及时间、数据层级和独立单位、分组或暴露、缺失与观察过程，再读取对应已审核规则。已有明确方案时直接评估其成立条件，不重复基础教学。

按目标检查随访、删失与竞争事件；混杂变量依据因果角色；连续变量允许临床合理的非线性；交互需明确尺度和比较；纵向或cluster数据不能按独立个体处理。少量中心时先查cluster数、每群信息、治疗分配层级和中心与治疗的可分离性。

区分模型选择、识别假设和软件执行。给与estimand一致的效应量、诊断、敏感性分析及结果解释。诊断P值不是自动开关，模型拟合良好也不证明无混杂、MAR或因果识别。不同estimand的结果列为补充问题，不伪装为同目标稳健性。

如果数据或关键结构不可访问，说明可确定的分析部分，给明确数据接口或条件分支；不得臆造分布、事件数、缺失机制或模型结果。必要时进入Implementation Mode。方案合理时直接认可并指出真正需要核对的实现细节。
